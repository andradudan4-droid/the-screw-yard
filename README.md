# The Screw Yard

Online catalogue for a screws and fixings business. Visitors browse products,
build a quote list and send it by WhatsApp or phone. There's no checkout: the
trade customer gets a price back.

**Live:** [thescrewyard.co.uk](https://thescrewyard.co.uk)

## Features

- Category pages (wood screws, drywall screws, concrete anchors, bolts, nails,
  rivets and more) and buying guides
- Quote list that persists while browsing and sends as a WhatsApp message
- Product data in one file (`js/data.js`). `tools/prerender.mjs` writes it into
  the HTML so search engines see the full catalogue without running JavaScript.
- Category and guide pages are generated by `tools/categories.mjs` and
  `tools/guides.mjs`
- Sitemap, FAQ, privacy, cookies and terms pages

## Run locally

```bash
node tools/prerender.mjs        # after editing js/data.js
python3 -m http.server 5178     # then open http://localhost:5178
```

Deployed on Cloudflare Workers (static assets). `worker/` only redirects `www`
to the main domain.

## Stack

- HTML, CSS, JavaScript (no framework, no build step)
- Node scripts for pre-rendering
- Cloudflare Workers
